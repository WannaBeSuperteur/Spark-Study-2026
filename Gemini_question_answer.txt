## Prompt

대용량 데이터의 메모리, 속도 문제를 개선하기 위해 PySpark DataFrame을 포함한 PySpark를 기초부터 학습할 때, 학습 주제를 15가지 추천해 줘.

## Response

Pandas에서 PySpark로 넘어가는 가장 큰 이유는 단연 "메모리 부족(OOM, Out of Memory)"과 "처리 속도 병목" 해결입니다.

PySpark는 단지 syntax를 배우는 것보다 "Spark가 분산 환경에서 메모리를 어떻게 관리하고 셔플링을 최적화하는가"라는 원리를 이해하는 것이 속도 개선의 80%를 차지합니다.

기초부터 시작해 대용량 데이터의 메모리·속도 문제를 해결하는 핵심 튜닝까지, 단계별 15가지 추천 학습 주제를 정리했습니다.

📌 Phase 1. Spark 동작 원리 및 핵심 개념 (1~3)
Pandas와의 가장 큰 차이점인 분산 처리 구조와 지연 연산을 이해하는 단계입니다.

1. Spark 클러스터 아키텍처

Driver, Executor, Worker Node, Cluster Manager의 역할 구분을 이해합니다.

메모리 핵심: 내가 작성한 코드가 Executor의 메모리 상에서 어떻게 분산 실행되는지 파악합니다.

2. RDD vs DataFrame vs Spark SQL

저수준 API(RDD)와 고수준 API(DataFrame)의 차이를 이해합니다.

속도 핵심: Catalyst Optimizer와 Tungsten Engine이 DataFrame 코드를 어떻게 자동 최적화하는지 배웁니다.

3. 지연 연산(Lazy Evaluation)과 DAG

Transformation(지연 연산)과 Action(실제 실행)의 차이를 명확히 구분합니다.

Spark가 실행 계획(DAG, Directed Acyclic Graph)을 작성하여 불필요한 연산을 줄이는 원리를 학습합니다.

📌 Phase 2. DataFrame 기본 변환 및 처리 (4~6)
실제 데이터를 조작하고 메모리 낭비를 줄이는 기초 코딩 기법입니다.

4. 명시적 스키마(Schema) 정의 및 파일 I/O

대용량 데이터 읽기 시 inferSchema=True가 왜 속도를 크게 떨어뜨리는지 이해하고, StructType으로 스키마를 직접 정의하는 방법을 배웁니다.

5. 핵심 Transformation & Action 연산

select, filter, withColumn, groupBy, agg 등 핵심 함수 사용법을 익힙니다.

6. Spark Built-in 함수 vs PySpark UDF (User Defined Function)

속도 핵심: Python 사용자 정의 함수(UDF)가 파이썬-자바(JVM) 간 직렬화 병목을 일으키는 이유를 이해하고, Spark 내장 함수 및 Pandas UDF (PyArrow 기반) 활용법을 배웁니다.

📌 Phase 3. 파일 및 저장 최적화 (7~8)
디스크 I/O를 줄여 읽기/쓰기 속도를 극대화하는 단계입니다.

7. 대용량 파일 포맷 및 압축 (Parquet, ORC, Snappy)

행 기반(CSV/JSON)과 열 기반(Columnar: Parquet) 파일 포맷의 차이를 이해합니다.

필요한 컬럼만 선별하여 읽는 Column Pruning과 Predicate Pushdown을 학습합니다.

8. 파티셔닝(Partitioning) & 버케팅(Bucketing)

partitionBy 및 bucketBy를 통해 조회 및 조인 속도를 비약적으로 높이는 기법을 익힙니다.

📌 Phase 4. 메모리 관리 및 성능 튜닝 (9~12)
대용량 데이터 메모리/속도 문제 해결의 핵심 구간입니다.

9. 파티션 제어와 셔플링(Shuffling): repartition vs coalesce

메모리/속도 핵심: 데이터가 네트워크를 통해 이동하는 Shuffle 비용을 최소화하고, 적절한 파티션 개수를 설정하는 공식(spark.sql.shuffle.partitions)을 배웁니다.

10. 메모리 캐싱 전략: cache() & persist()

재사용되는 DataFrame을 메모리(MEMORY_ONLY) 또는 디스크(MEMORY_AND_DISK)에 저장하여 반복 연산 시간을 줄이는 법을 배웁니다.

11. Join 최적화 및 Data Skew(데이터 편향) 대응

작은 테이블과 조인할 때 네트워크 셔플을 없애는 Broadcast Join을 학습합니다.

특정 파티션에만 데이터가 쏠려 OOM이 터지는 Data Skew 해결 기법(Salting 등)을 익힙니다.

12. Spark UI 분석 및 병목 진단

Spark 웹 UI를 통해 DAG 그래프, Stage 분한, Task 소요 시간, Spill (Memory -> Disk) 발생 여부를 확인하고 진단하는 실무 감각을 기릅니다.

📌 Phase 5. 실전 트러블슈팅 및 확장 (13~15)
실제 운영 환경에서 자주 발생하는 에러를 해결하는 단계입니다.

13. Out of Memory (OOM) 예외 트러블슈팅

Driver OOM과 Executor OOM의 차이를 구분하고, Memory Overhead 설정 및 메모리 배분 옵션을 조절하는 방법을 배웁니다.

14. PySpark Pandas API (formerly Koalas) 연동

기존 Pandas 코드를 최소한의 변경으로 분산 처리할 수 있는 pyspark.pandas 모듈 사용법과 가이드라인을 익힙니다.

15. 메모리 효율적인 대용량 ETL 파이프라인 구축 실습

1~14에서 배운 개념(스키마 정의, Parquet 저장, Broadcast Join, Spark UI 모니터링)을 종합하여 단일 엔드투엔드 파이프라인을 작성해 봅니다.
